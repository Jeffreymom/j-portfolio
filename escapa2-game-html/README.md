# ESCAPA HTML 게임

빨간 블록을 마우스나 손가락으로 드래그하여 파란 장애물과 벽을 피하는 반응속도 게임입니다.

## 실행 방법
1. 폴더를 VS Code로 엽니다.
2. `index.html`을 실행합니다.
3. Live Server를 사용하면 모바일 테스트가 편합니다.

## 파일
- `index.html` : 화면 구조
- `style.css` : 반응형 디자인
- `script.js` : 게임 로직, 충돌 판정, 기록 저장

## 주요 기능
- PC 마우스 + 모바일 터치 지원
- Canvas 기반 게임
- 파란 장애물 자동 이동 및 벽 반사
- 충돌 시 결과 모달
- 최고 기록 localStorage 저장
- 반응형 화면
- 간단한 효과음 On/Off
