# ODD ONE OUT — 틀린 하나 찾기

같은 문자, 숫자, 기호, 이모지 사이에서 다른 하나를 빠르게 찾는 HTML 게임입니다.

## 실행 방법
1. 압축을 풉니다.
2. VS Code로 폴더를 엽니다.
3. `index.html`을 Live Server로 실행합니다.

## 주요 기능
- 총 30레벨
- 레벨별로 격자 수 증가
- 문자, 숫자, 기호, 한글, 한자, 이모지 문제
- 실시간 타이머
- 오답 횟수 기록
- 정확도 및 최종 등급
- 최고 기록 localStorage 저장
- 모바일 터치 및 PC 마우스 지원
- 방향키와 Enter 키 지원
- 효과음 켜기/끄기

## 파일 구조
- index.html
- style.css
- script.js
